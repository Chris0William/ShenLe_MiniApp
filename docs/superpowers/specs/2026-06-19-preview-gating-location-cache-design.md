# 匿名预览门禁与定位缓存优化设计

## 背景

当前匿名/游客可进入地图和房源列表的脱敏预览态，但体验和边界仍需收紧：筛选和手动选点不应对匿名/游客开放；地图和列表各自触发定位，可能造成重复授权；公共预览接口因 `<3 个楼盘` 的限制只展示少量区域；页面中存在“当前账号待开通...”提示条，干扰预览体验。

本轮不处理位置名称解析，不接腾讯/高德/任何外部地图服务，不新增地图 Key 或合法域名。

## 目标

- 匿名/游客默认可看脱敏区域预览，但不能使用筛选、搜索、手动选点或进入真实详情。
- 地图页和房源列表页共用一次自动定位结果，避免重复弹 `uni.getLocation` 授权。
- 删除显式“定位”按钮，仅保留页面进入时自动定位和普通用户以上可用的“选点”。
- 公共预览尽量展示所有可展示区域，不再因少于 3 个楼盘直接隐藏。
- 删除游客提示条，保持预览页干净。

## 非目标

- 不做经纬度转地址名称。
- 不接入高德、腾讯或其他外部逆地理服务。
- 不新增微信合法域名配置。
- 不向匿名/游客开放真实楼盘名称、真实楼盘坐标、房源详情、媒体或房源 ID。
- 不改用户端完整找房功能；本轮只改当前地图/房源列表预览链路。

## 前端设计

### 共享定位状态

新增轻量定位工具模块，例如 `src/utils/location-cache.ts`。

职责：

- 缓存最近一次 `uni.getLocation` 成功结果。
- 合并并发定位请求，多个页面同时调用时只触发一次真实定位。
- 定位成功后返回 `longitude`、`latitude`、`label: '当前位置'`。
- 定位失败时返回失败状态，由页面保留默认深圳中心点作为距离参考；不重复弹授权。

地图页和房源列表页进入时调用同一个定位方法。若已有缓存，直接复用并刷新数据；若没有缓存，触发一次自动定位。

### 删除“定位”按钮

- 地图页头部删除“定位”按钮，只保留“选点”和“刷新”。
- 房源列表位置卡删除“定位”文字按钮，只保留“选点”。
- 页面仍在进入时自动定位，成功后顶部显示“当前位置”。

### 手动选点门禁

- 普通用户及以上：点击“选点”调用 `uni.chooseLocation`，显示微信返回的 `name || address || '选定位置'`。
- 匿名/游客：点击“选点”不打开 `uni.chooseLocation`，直接调用 `ensureCanUse('登录并通过审核后可选择位置')`。

### 筛选门禁

当前 `sl-property-filter-bar` 继续保留视觉展示，但新增门禁入口：

- 地图页、房源列表页在预览态传入禁用/门禁配置。
- 匿名/游客点击位置、租金、搜索、重置等筛选动作时，不打开筛选面板，也不提交筛选；直接触发登录/申请。
- 普通用户及以上维持旧筛选行为。

这样可以避免匿名/游客通过筛选反推真实楼盘或房源存在性。

### 删除游客提示条

删除地图页和房源列表页的 `guest-strip` 结构和样式，包括文案“当前账号待开通，申请通过后可查看完整房源”。受保护动作仍通过点击时的登录/申请提示完成。

### 预览列表加载

房源列表预览态加载公共区域预览时使用足够大的 `pageSize` 或一次性累积全部结果，不再做“加载更多时要求登录/申请”。因为返回的是脱敏区域聚合信息，展示全部区域是可接受的。

## 后端设计

修改 `SlPublicService.BuildRegionPreviewAsync`：

- 去掉 `communityCount < 3` 直接 `continue` 的限制。
- 仍要求区域有 `CenterLng/CenterLat`，地图只使用区域中心点，不回退到真实楼盘坐标。
- 仍要求有可租房源数据；没有可租数据的区域不展示。
- 低数量区域继续使用模糊文案：`1-9 个楼盘`、`少量房源`、`租金面议/约 xx-xx 元`。
- 不返回真实楼盘 ID、楼盘名称、房源 ID、媒体、地址或真实坐标。

## 安全边界

- 匿名/游客仅访问 `/api/slPublic/regionMap` 和 `/api/slPublic/regionPage` 这类脱敏接口。
- 真实接口 `/api/slCommunity/*`、`/api/slProperty/*` 维持 777+ 权限要求。
- 前端门禁只负责体验；真实数据安全仍以后端接口隔离为准。

## 验证计划

### 后端

- `dotnet build .\ShenLe.sln --no-restore`
- 调用 `/api/slPublic/regionMap`，确认返回区域数量不再受 `<3 个楼盘` 限制。
- 匿名调用 `/api/slCommunity/page` 仍返回业务 401。

### 小程序

- `pnpm type-check`
- `pnpm build:mp-weixin`
- 微信开发者工具 MCP `compile`：`compiled: true`、`errors: []`、`warnings: []`
- 匿名/游客地图页：显示区域 marker；点击筛选触发登录/申请；点击选点触发登录/申请；无“定位”按钮；无游客提示条。
- 匿名/游客房源列表页：显示所有脱敏区域预览；点击筛选触发登录/申请；点击选点触发登录/申请；无“定位”按钮；无游客提示条。
- 普通用户及以上：筛选和手动选点仍可用。
- 自动定位：地图页和房源列表页切换时不重复触发定位授权。

## 风险与处理

- 如果微信运行时仍因系统权限策略弹窗，前端只能保证代码层不重复调用 `uni.getLocation`；真实弹窗行为需在 DevTools 和真机上验证。
- 如果某些区域缺少 `CenterLng/CenterLat`，地图页不会展示该区域；这符合不使用真实楼盘坐标兜底的安全边界。
- 如果预览区域数量较多，列表一次性加载可能增加一点首屏请求体积；当前区域规模可接受，后续再按脱敏分页优化。
