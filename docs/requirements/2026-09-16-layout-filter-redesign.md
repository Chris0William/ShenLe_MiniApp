## 问题一：地图页下拉面板层级穿透（bug，截图已确认）

- 现象：地图页打开"户型"下拉面板时，地图上的 **"472 个楼盘"角标** 从面板底部**穿透显示**；点开楼盘卡片时也有元素穿透上来。
- 原因（初判）：地图 marker/callout 是**原生组件**，层级高于普通 view，`z-index` 拉不开；下拉面板的 `filter-mask` 只盖住了普通内容层。历史上有同类问题（"地图蓝屏"=双 map 实例）。
- 修复方向：
  1. 面板打开时给 map 组件加 `cover-view` 遮罩（原生层级），或
  2. 用 `wx:if` 条件隐藏地图标记层（`markers`/`callout` 置空）再渲染面板，或
  3. 面板打开时把 map 移出渲染树（保留背景色）
  - 选型注意：方案 1 最平滑（不闪）；楼盘卡片穿透点也要一并核查（选中卡片 z-index 与 mask 层级）
- 回归范围：位置/租金/筛选三个下拉 + 楼盘选中卡片 + "仅看"快捷行 + 已选 chip 栏

## 问题二：户型筛选改版（需求）

### 固定预设（多选，首选交互）
| 预设名 | 匹配规则 |
|---|---|
| 单间 | 1室 0厅 任意卫 |
| 一室一厅 | 1室 1厅 任意卫 |
| 两室一厅 | 2室 1厅 任意卫 |
| 三室一厅 | 3室 1厅 任意卫 |
| 其他 | 选择"其他"时展开 自由组合面板 |

### "其他"自由组合
- 展开三段选择：室 0-5+、厅 0-3、卫 0-3（0 也可选）
- 用户组合出一个完整组合（如 2室2厅1卫）→ **确定后生成一个小标签**加入多选集合
- 可继续组合多个"其他"标签；预设与自定义标签混选，同为 OR 关系

### 数据语义（重要——需设计）
- 预设 = 三元组约束（bedrooms/livingRooms 精确 + 卫不限制）
- 当前后端 `bedroomsList/livingRooms/bathrooms` 是**同段 OR、跨段 AND** 语义，**无法表达"1室1厅 或 2室1厅"这种跨段组合 OR**
- 方案：后端新增 `layoutCombinations: string[]`（如 `"1,1,*"` / `"2,1,*"`，`*` 表示不限），查询时每个组合是一个 (室,厅,卫) 精确匹配的 OR 集合；预设和自定义标签都编译成组合列表下发，保持旧参数兼容

### 交互
- "户型"独立 tab 保留（截图现状），面板内：顶部固定预设 chips（多选）+ "其他"展开区
- 已选展示沿用 chip 栏：预设显示名称（"单间"/"两室一厅"），自定义显示 `x室x厅x卫`
